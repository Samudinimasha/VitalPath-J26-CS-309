Component 2 Architecture & Mathematical Foundation

Deterministic, Machine Learning-Free Adaptive Security Decision Engine (SLIIT IT23471962 / J26-CS-309)

1. Device Trust (DTS) - 35%

Shared SQLite interface with Component 1. BLOCKED devices clamped to 0.00. High trust inverts risk contribution: (1 - DTS).

2. Clinical Criticality (CC) - 45%

Deterministic AHA/WHO classification of HR, SpO2, SBP/DBP, and RESP. Normal=0.20, Borderline=0.60, Life-Critical=1.00.

3. Network Condition (NC) - 20%

5G channel latency, packet loss, and handovers. Handover events add +0.30 penalty to preempt cell-edge interception.

Deterministic SPS Formula:
SPS = (0.35 × (1 - DTS)) + (0.45 × CC) + (0.20 × NC)
Cryptographic Profile Boundaries:
• Standard (SPS ≤ 0.40) : AES-256-GCM, 300s session key rotation
• Enhanced (0.40 < SPS ≤ 0.75): AES-256-GCM, 60s session key rotation
• Maximum (SPS > 0.75) : AES-256-GCM + ECDSA P-256 Signature, 10s rotation
